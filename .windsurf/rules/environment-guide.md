Always check the project's file structure before running terminal commands.

Examples

- Check if a directory/file exists before creating it
- Activate a virtual environment if one exists
- Verify you’re in the correct working directory
- Ensure required files (e.g. .env, requirements.txt, package.json) are present before installing or running dependencies
- Check if a Git repository is initialized before running Git commands
- Make sure relevant scripts (e.g. start.sh, setup.py) exist before trying to execute them
- Look for configuration files (like .vscode, .prettierrc, tsconfig.json) before assuming default settings
- Confirm a .gitignore file exists before adding new rules
